#  My Homepage 2.0

안녕하세요! 저의 일상과 관심사, 그리고 지금까지 진행한 프로젝트를 기록하기 위해 만든 개인 홈페이지입니다.

웹프로그래밍 수업에서 배운 HTML, CSS, JavaScript를 활용해 직접 제작했으며, Firebase를 연동해 방문자와 소통할 수 있는 기능도 추가했습니다.

## 🌐 홈페이지 바로가기

**[My Homepage 2.0 방문하기](https://kimyudam.github.io/MyHompage/)**

별도의 설치 없이 링크를 클릭하면 홈페이지를 둘러볼 수 있어요!

## ✨ 주요 기능

### 🏠 HOME
홈페이지의 첫 화면입니다.

간단한 소개와 함께 최근에 작성한 MY DAILY 게시글을 확인할 수 있습니다.

### 👩‍💻 ABOUT ME
저에 대한 소개를 담은 공간입니다.

현재 공부하고 있는 분야와 관심사, 기술 등을 소개합니다.

### 💻 PROJECT & ACTIVITY
지금까지 진행한 프로젝트와 활동을 정리한 공간입니다.

프로젝트 소개와 관련 GitHub 저장소도 확인할 수 있습니다.

### 📸 MY DAILY
일상과 추억을 기록하는 작은 블로그입니다.

- 게시글 제목과 내용 작성
- 게시글에 사진 첨부 (최대 5장)
- 게시글 검색 및 필터링
- 최신 게시글 5개 표시
- 관리자 로그인 후 게시글 작성 및 관리

게시글은 Firebase Firestore에 저장되며, 사진은 프로젝트의 이미지 폴더를 통해 제공됩니다.

### 💬 GUESTBOOK
홈페이지를 방문한 사람들이 자유롭게 메시지를 남길 수 있는 공간입니다.

- 방문자 방명록 작성
- 작성된 메시지 실시간 확인
- 작성자 본인의 메시지 관리
- 관리자의 방명록 관리

## 🛠️ 사용 기술

| 기술 | 활용 |
|---|---|
| HTML5 | 홈페이지 구조 |
| CSS3 | 디자인 및 레이아웃 |
| JavaScript | 화면 동작 및 기능 구현 |
| Firebase Authentication | 사용자 인증 |
| Firebase Firestore | 게시글 및 방명록 데이터 저장 |
| GitHub Pages | 웹사이트 배포 |
